Carrier settings

The SMS domain is the setting that lets VoLTE and SMS work together. AT+CGSMS does not write through to it — it is a Qualcomm NV item, edited directly here.
Changing the SMS domain or IMS needs a module reset (~40 s) before it takes effect.

Time and NTP

There is no RTC battery on this board, so after a power cut the clock stays at whatever it was when the power went until NTP lands. That is not cosmetic: TLS certificate validation and the prepaid reminder both read dates from it, and log timestamps around a boot cannot be trusted until Synchronized below says yes.
The LAN gateway answers faster than the public pool and keeps working when the WAN does not.

Recovery number

Where a reset code is sent by SMS if the password is forgotten. The board sends it through its own SIM, so no mail server is involved. If the modem is down, reset on the board instead: python3 ~/phone/manage.py set-password
